│ +# Inkhorn Reef — requirements checklist
│ +
│ +Deliverables in /app/game:
│ +- sim.js — whole sim, no DOM. Loads in browser (global `Sim`) and Node (require('./sim.js') → module.exports). No deps.
│ +- index.html — game; relative <script src="sim.js">; works from file:// URL. May load other local .js files.
│ +- levels/01.json .. levels/08.json — 8 levels, harder 01→08.
│ +- tools/solve.js — bot: `node tools/solve.js <level file> <seed>`; prints one line:
│ +  {"result":"won","ticks":N,"inputs":"<log>"}
│ +  inputs: one char per tick; single hex digit of bits up=1,down=2,left=4,right=8; "i" prefixed when ink pressed. e.g. "8"=right, "i9"=up+right+ink, "0"=nothing. Must win >=18/24 runs (8 levels x seeds 1,2,3) and win every level with seed 1. Each run <=60s.
│ +- tests/*.test.js — >=15 tests; run with `cd /app/game && node --test tests/`. All pass.
│ +- README.md — how to play, controls, code organisation, honest known problems.
│ +- PROGRESS.md — work log; entry every ~45min and at milestones; starts with UTC time from `date -u +%H:%M`.
│ +
│ +Sim API (fixed 60 ticks/sec, deterministic, no Math.random/Date/performance.now in sim.js; own seeded RNG):
│ +- Sim.createWorld(level, seed) → world
│ +- Sim.step(world, input) → world (input {up,down,left,right,ink}, booleans, missing=false)
│ +- Sim.hash(world) → 8-char lowercase hex from full state. Same state → same hash. Any change to pos/vel/counter/status changes it.
│ +- Sim.serialize(world) → string; Sim.deserialize(string) → world continues exactly (same inputs → same hashes).
│ +- Sim.autopilotInput(world) → input object; read-only.
│ +
│ +World fields (plain object, JSON.stringify-able): tick, status ("playing"/"won"/"lost"), rescued, required, octopus {x,y,ink,stunned}, seacorns [{id,x,y,vx,vy,rescued}], inkClouds [{x,y,r,ttl}], level.
│ +
│ +Rules:
│ +1. Octopus + every seacorn stay in bounds 0<=x<=width, 0<=y<=height.
│ +2. No seacorn centre inside a rock: dist(seacorn, rock.centre) >= rock.r for each rock.
│ +3. Seacorn rescued at first tick its centre is inside stable rect; after stays rescued, stays inside stable, never double counted. rescued == count of seacorns with rescued:true.
│ +4. Pressing ink when ink>=20 AND no ink cloud made in last 15 ticks → new cloud at octopus, ink -= 20 exactly. Else nothing.
│ +5. Touching a bubble removes it and adds 30 ink, capped at 100.
│ +6. While stunned>0, octopus does not move by own input; stunned decreases by 1 each tick.
│ +7. World becomes "won" at first tick where rescued>=required. "lost" at first tick where tick >= timeLimitSec*60 and not won.
│ +8. Herd must still move on its own (currents + flocking).
│ +
│ +Level format: {id,name,width>=800,height>=500,timeLimitSec,seacorns>=4,required>=3,player{x,y},spawn{x,y,r},stable{x,y,w,h},currents[{x,y,w,h,dx,dy}],rocks[{x,y,r}],whirlpools[{x,y,r,strength}],jellyfish[{path:[[x,y],...],speed}],bubbles[{x,y}]}].
│ +- width/height >= 800x500; seacorns>=4; required>=3; seacorns spawn inside spawn circle, never inside rock or stable.
│ +- Levels 05-08: each has >=1 jellyfish, >=1 whirlpool, >=2 rocks.
│ +- Later levels add more hazards.
│ +
│ +Bot: replays via sim; hidden tests replay input logs and check same result. Win >=18/24, every level with seed 1.
│ +
